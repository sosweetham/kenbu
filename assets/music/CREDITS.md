# Menu music credits

Ambient music for the song picker, played while no song preview is playing.

Every file here is the author's own published file, unmodified: nothing was trimmed,
re-encoded or converted. Only the file names were changed. All five were downloaded
from OpenGameArt.org on 2026-11-16 from the uploader's own submission page, and in
each case the uploader is the composer.
